# TypeScript 7 実践入門 練習用ファイル

書籍『TypeScript 7 実践入門 基礎からフロントエンド・バックエンド開発まで』（早瀬 透）の練習用ファイルです。
本の中で作るタスク管理の Web アプリ「tasks」のコードを、章ごとに置いています。

## 章ごとのファイルの取り方

各章を終えた時点のファイルに、`ch01`〜`ch13` の印（Git のタグ）を付けています。本文のコードの枠と、各章の印の時点のファイルは同じ内容です。

- 印の付いた ZIP を展開すると、`typescript7-jissen-samples-ch03` のような名前のフォルダーができ、その中に `tasks` フォルダーがあります
- `tasks` フォルダーを VS Code で開き、ターミナルで `npm install` を打ってから使います（`node_modules` と `dist` は入っていません）
- Git を使う人は `git clone https://github.com/fairview2311/typescript7-jissen-samples.git` の後、`git checkout ch03` のように章の印に切り替えます

## ブランチ

- `main`: 第1章を始める前の状態
- `solutions`: いちばん新しい章を終えた状態

## 動かす環境

Node.js 24 以降（LTS）、TypeScript 7.0、VS Code と拡張機能「TypeScript 7」。詳しくは本の第1章を見てください。
